# Power Desk

## Platform
Native Windows desktop.
## Stack
User confirmed native Windows and Stella styling. Python/PyQt5 uses the existing installed runtime.
## Purpose
Four manual power modes, real sensor auditing, advanced controls, optional task rules, and visible shell commands. User wants an original interface, not HWMonitor UI.
## Constraints
Preserve original power settings; supported controls only, transparent permission failures. No BIOS flashing, unsafe voltage/clock tuning or security changes. Whole-PC watts cannot be inferred from GPU watts.
